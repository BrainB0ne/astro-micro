## 👋 Intro

Today, I needed an icon for <Link external href="https://threema.com">Threema</Link>
to add to my <Link href="/contact">contact</Link> page.

I could not find it in the <Link external href="https://tabler.io/icons">Tabler Icons</Link> set (at the time of writing this post),
so I decided to make a new unofficial icon myself with <Link external href="https://inkscape.org">Inkscape</Link>.

It's basically a combination of the already existing <Link external href="https://tabler.io/icons/icon/lock">lock.svg</Link>
and <Link external href="https://tabler.io/icons/icon/message-circle">message-circle.svg</Link>.
