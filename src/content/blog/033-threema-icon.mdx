Today, I needed an icon for <Link external href="https://threema.com">Threema</Link> to add to my contact page.

I could not find it in the Tabler Icons set (at the time of writing this post),
so I decided to make a new icon myself with <Link external href="https://inkscape.org">Inkscape</Link>.

It's more or less a combination of the already existing <Link external href="https://tabler.io/icons/icon/lock">lock.svg</Link>
and <Link external href="https://tabler.io/icons/icon/message-circle">message-circle.svg</Link>.

This is the resulting icon I used on my contact page:

<div class="justify-self-start">
  <img src="/svg/brand-threema.svg" width="128" height="128" alt="Threema Icon" />
</div>

Maybe this icon or something similar can be added to the
<Link external href="https://tabler.io/icons">Tabler Icons</Link> set in the future by the Tabler team.
