## 👋 Introduction
ChatGPT-EX is an **Electron wrapper for ChatGPT** that runs ChatGPT in its own desktop window instead of a browser tab.
It is a fork of <Link external href="https://github.com/jfscoertzen/ChatGPT-client">jfscoertzen/ChatGPT-client</Link>.

**ChatGPT-EX is partially vibe-coded with OpenCode: OpenAI GPT-5.5 🤖**

The goal is simple: keep the official ChatGPT web experience, but add the desktop behavior I want day to day: quick refresh, a tray icon, local exports, print support and a few quality-of-life controls around the app window.

The original <Link external href="https://github.com/jfscoertzen/ChatGPT-client">ChatGPT-client</Link> application was made only for Linux, because of the lack of an official ChatGPT app.

More information is available on a blog post of the author: <Link external href="https://dev.to/jfscoertzen/chatgpt-desktop-client-for-linux-28al">ChatGPT Desktop Client for Linux</Link>

I liked the idea also for Windows, so I added a Windows build, even though an official ChatGPT app already exists.

The application loads `https://chatgpt.com` directly.
Prints, Markdown and PDF exports are generated from the conversation that is already rendered in the window, then saved locally through Electron.
No extra OpenAI API calls are made for exporting or printing.

This project is currently built with **Electron 43** and packaged with **electron-builder**.

## ❗ Build Requirements
- **Node.js 24**
- **npm** is used for dependency management.
- **Linux builds** produce AppImage and Debian packages.
- **Windows builds** produce an NSIS installer and a portable executable.

```bash
npm install
npm start
```

Build packages with:

```bash
npm run build:linux
npm run build:win
```

## ✨ Features
- **Dedicated desktop window** - ChatGPT opens as a standalone Electron app.
- **Bottom-right action buttons** - Refresh, Print, Markdown export, and PDF export are available inside the app window in a compact 2x2 layout.
- **Local Markdown export** - Saves the currently rendered chat as `chatgpt-export-YYYY-MM-DDTHH-MM-SS.md`.
- **Local HTML export** - Saves the currently rendered chat as `chatgpt-export-YYYY-MM-DDTHH-MM-SS.html`.
- **Local PDF export** - Saves the currently rendered chat as `chatgpt-export-YYYY-MM-DDTHH-MM-SS.pdf` using Electron's local `printToPDF` support.
- **Print** - Prints the currently rendered chat.
- **Export preferences** - Choose a default export folder, toggle timestamps, toggle User/Assistant role headings, choose PDF page size, and optionally save exports without a dialog.
- **Export/print notifications** - Shows a temporary in-window confirmation after successful Markdown export, PDF export, or print.
- **Drag-and-drop uploads** - Drop images/files into the app window to add them to the ChatGPT prompt.
- **Compatibility Mode** - Optional Chrome-like user agent mode for site compatibility, with platform-specific Windows and Linux user agents.
- **Voice/Microphone privacy setting** - Microphone/recording access is disabled by default and can be enabled from the tray settings.
- **System tray integration** - Closing the window can hide it to the tray instead of quitting the app.
- **Tray settings** - Toggle close-to-tray, start minimized, always-on-top behavior, Compatibility Mode, and Voice/Microphone Access.
- **Browsing-data cleanup** - Clear cookies, cache, local storage, IndexedDB, and service worker data from the tray menu.
- **Native edit context menu** - Right-click for cut, copy, paste, and select all.
- **F5 reload shortcut** - Reload ChatGPT without leaving the app.
- **Spell checking disabled** - Prevents the embedded browser spellchecker from interfering with typing.
- **Developer Tools** - tray action or F12 toggles Chromium DevTools in a detached window.
